BotBot 隐私政策

生效日期：2026 年 11 月 24 日 · 适用平台：iOS · 开发者：个人开发者（qkunio）

欢迎使用 BotBot。BotBot 是一款由个人开发者打造的纯原生 iOS 客户端，采用自带 API Key（BYOK）模式直接与 DeepSeek 官方 API 通信。本隐私政策清晰说明应用如何处理你的数据与系统权限。

1. 我们不收集任何个人数据

  • BotBot 没有自有后端服务器，不提供账号注册或云端同步服务。
  • 开发者不会收集、读取、存储或出售你的姓名、邮箱、API Key、聊天记录、语音数据、附件文件或设备标识符。
  • 应用内不集成任何第三方统计分析、广告或跨应用追踪 SDK。

2. 本地数据存储与清除

以下数据仅保存在你的 iOS 设备应用沙盒本地，不会上传至开发者服务器：

  • API Key 与应用偏好：通过系统 UserDefaults 保存在本机（包含 API Key、深度思考/联网搜索开关、自动朗读设置、本地昵称等）。
  • 对话记录、草稿与附件原件：以本地文件形式保存在应用沙盒中；通过链接或 ZIP 导入的历史对话也仅在本地解析并保存。
  • 完全可控：你随时可在应用内通过「设置 → 删除所有数据」一键永久清除本机全部聊天记录、草稿、头像、昵称、API Key 及设置，或直接卸载应用以彻底移除本地数据。

3. 与第三方 API 服务的直接通信

当你主动使用以下功能时，你的设备会直接向 DeepSeek 官方服务（https://api.deepseek.com）发起加密 HTTPS 请求：

  • 发送聊天消息、生成对话标题、使用深度思考或联网搜索功能；
  • 核验 API Key 有效性及查询账户余额；
  • 上传图片或文件附件（DeepSeek Files API）；
  • 语音输入识别（DeepSeek ASR）与回复流式朗读（DeepSeek TTS）。

上述传输至 DeepSeek 的内容将受 DeepSeek 的服务条款与隐私政策约束。此外，如果你在聊天中主动粘贴外部历史记录下载链接或点击参考网页链接，设备将直接访问对应链接或通过系统 SafariView 打开网页。

4. 系统权限说明

  • 麦克风权限：仅在你主动使用语音输入功能时请求，用于录制音频并发送给 DeepSeek 语音识别接口转为文字，不会在后台静默录音。
  • 相机权限：仅在你主动选择拍照添加消息附件时请求。
  • 照片图库权限：仅在你主动选择相册图片作为聊天附件或设置个人本地头像时请求。

5. 儿童隐私

本应用不面向 13 周岁以下儿童（或当地法律规定的同等最低年龄），也不会有意收集任何儿童的个人信息。

6. 政策更新与联系我们

如本隐私政策有更新，我们会在此页面发布最新内容并更新生效日期。如果你对本隐私政策有任何疑问或建议，请通过以下页面联系开发者：

https://github.com/qkunio/botbot-ios-site/issues

BotBot Privacy Policy

Effective Date: November 24, 2026 · Platform: iOS · Developer: Independent Developer (qkunio)

Thank you for using BotBot. BotBot is a pure native iOS client developed by an independent developer using a Bring Your Own Key (BYOK) architecture that communicates directly with the official DeepSeek API. This Privacy Policy explains how your data and device permissions are handled.

1. No Personal Data Collection

  • BotBot operates no developer-hosted backend servers, user accounts, or cloud sync services.
  • The developer does not collect, access, store, or sell your personal information, API keys, chat history, voice recordings, attachments, or device identifiers.
  • The app contains no third-party analytics, advertising, or cross-app tracking SDKs.

2. On-Device Storage & Data Deletion

All app data is stored strictly inside your iOS device's local sandbox:

  • API Key & Preferences: Stored locally via iOS UserDefaults (API key, Deep Thinking/Web Search toggles, read-aloud voice settings, local profile nickname).
  • Conversations, Drafts & Attachments: Saved locally as files within the app sandbox. Chat history imported via download link or ZIP archive is parsed and stored locally only.
  • Full User Control: You can permanently wipe all local conversations, drafts, avatar, nickname, API key, and settings anytime via Settings → Delete All Data, or by uninstalling the app.

3. Direct Communication with Third-Party APIs

When you actively initiate requests in the app, your device connects directly via HTTPS to DeepSeek's API (https://api.deepseek.com) for:

  • Sending chat messages, auto-generating titles, Deep Thinking, and Web Search;
  • Validating your API key and checking account balance;
  • Uploading image or file attachments (DeepSeek Files API);
  • Voice-to-text transcription (DeepSeek ASR) and streaming text-to-speech playback (DeepSeek TTS).

Data transmitted to DeepSeek is governed by DeepSeek's own Terms of Service and Privacy Policy. When you paste an external history archive URL or open cited web links via SafariView, your device connects directly to those URLs.

4. Device Permissions

  • Microphone: Requested only when using voice input to record speech for DeepSeek ASR transcription. Never accessed in the background.
  • Camera: Requested only when taking a photo to attach to a chat message.
  • Photo Library: Requested only when selecting photos to attach to messages or setting a local profile avatar.

5. Children's Privacy

BotBot is not directed to children under 13 (or the equivalent minimum age in your jurisdiction), and we do not knowingly collect personal information from children.

6. Changes & Contact

Updates to this Privacy Policy will be posted on this page with an updated effective date. For questions, support, or privacy inquiries, please contact the developer at:

https://github.com/qkunio/botbot-ios-site/issues
