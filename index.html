隐私政策摘要

生效日期：2026 年 11 月 24 日 · 适用应用：BotBot（iOS）· 开发者：个人开发者（qkunio） · 查看完整独立隐私政策页 →

BotBot 是一款无自有后端的自带 API Key（BYOK）本地客户端，我们高度重视你的隐私与数据控制权：

  • 零收集与零追踪：开发者不运营任何中转服务器，不收集你的个人身份信息、聊天记录、API Key 或使用行为统计，应用内不含第三方广告或追踪 SDK。
  • 本地存储：你的 DeepSeek API Key、偏好设置、自定义头像昵称、会话记录与附件原件仅保存在你的 iOS 设备本地沙盒中，随时可通过「设置 → 删除所有数据」永久清空。
  • 直接通信：仅当你主动发送消息、上传附件、使用语音输入/朗读或核验余额时，相应内容会直接发送至你配置的 DeepSeek 官方接口（https://api.deepseek.com），由 DeepSeek 按其隐私政策处理。
  • 系统权限：麦克风（仅用于语音输入录音）、相机（仅用于拍照添加消息附件）、相册（仅用于选择照片作为附件或头像），均仅在主动触发对应功能时请求。
  • 联系与支持：如有隐私疑问或使用反馈，请通过 GitHub Issues 联系开发者。

Privacy Policy Summary

Effective Date: November 24, 2026 · App: BotBot (iOS) · Developer: Independent Developer (qkunio) · Open Standalone Privacy Policy →

BotBot is a local-first BYOK (Bring Your Own Key) client with no developer backend. We respect your privacy and data ownership:

  • No Collection or Tracking: The developer operates no intermediary servers and collects no personal data, chat logs, API keys, or analytics. The app contains no third-party ad or tracking SDKs.
  • Local Storage: Your DeepSeek API key, preferences, profile avatar/nickname, conversations, and attachments are stored strictly inside your device's local sandbox and can be permanently erased anytime via Settings → Delete All Data.
  • Direct API Requests: When you send messages, upload attachments, use voice input/read-aloud, or check account balance, relevant data is transmitted directly from your device to DeepSeek's API (https://api.deepseek.com), governed by DeepSeek's Privacy Policy.
  • Device Permissions: Microphone (voice input), Camera (taking photos to attach), and Photo Library (selecting photos for attachments or avatar) are requested only when you actively use those features.
  • Support & Contact: For privacy questions or feedback, please reach out via GitHub Issues.
